- PsySym follow-up (PsyCoTalk): https://arxiv.org/abs/2510.25232
- ReDSM5: https://arxiv.org/abs/2508.03399

“Latest” and “authoritative” are kept distinct: a newer paper that only mentions a dataset is not treated as a stronger source than the dataset paper, while a newer paper is included when it materially reuses the data.
