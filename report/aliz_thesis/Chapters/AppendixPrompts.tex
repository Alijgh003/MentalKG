\chapter{امضاهای ساختاریافته و دستورهای مدل}\label{app:prompts}

این پیوست، امضاهای ساختاریافته مورد استفاده برای فراخوانی مدل زبانی را ثبت می‌کند. استفاده از \lr{DSPy} قالب ورودی و خروجی فراخوانی‌ها را ثابت و قابل بازتولید می‌کند.

\section{زنجیره فکر و بازیابی متن}
\begin{latin}\footnotesize\begin{verbatim}
class AnswerWithCoT(dspy.Signature):
    question: str = dspy.InputField(desc="Original post and question with labels")
    valid_labels: list[str] = dspy.InputField(desc="Complete allowed labels")
    answer: str = dspy.OutputField(desc="Exactly one value from valid_labels")

program = dspy.ChainOfThought(AnswerWithCoT,
    rationale_field=dspy.OutputField(desc="Brief decisive reasoning"))
\end{verbatim}
\end{latin}

این امضا در روش‌های \lr{Vanilla RAG} و \lr{HippoRAG 2} با شواهد بازیابی‌شده تکمیل می‌شود:
\begin{latin}\footnotesize\begin{verbatim}
class AnswerFromPsychiatricEvidence(dspy.Signature):
    question: str = dspy.InputField(desc="Original post and question")
    evidence: list[dict[str, str]] = dspy.InputField(desc="Retrieved passages with IDs")
    valid_labels: list[str] = dspy.InputField(desc="Complete allowed labels")
    answer: str = dspy.OutputField(desc="Exactly one value from valid_labels")
    cited_passage_ids: list[str] = dspy.OutputField(desc="Useful passage IDs")
program = dspy.ChainOfThought(AnswerFromPsychiatricEvidence)
\end{verbatim}
\end{latin}

\section{امضاهای روش \lr{ToG-1}}
در پیاده‌سازی نهایی \lr{ToG-1} کلاس امضای جداگانه‌ای در \lr{DSPy} تعریف نشد و استخراج موجودیت و تولید پاسخ با الگوهای مستقیم دستور انجام گرفت.

\section{امضاهای روش \lr{ToG-2}}
\begin{latin}\footnotesize\begin{verbatim}
class TopicEntityExtraction(dspy.Signature):
    post: str = dspy.InputField(desc="Complete post and classification question")
    allowed_labels: list[str] = dspy.InputField(desc="All possible classes")
    k: int = dspy.InputField(desc="Maximum entity names")
    entities: list[str] = dspy.OutputField(desc="Up to k distinct surface forms")

class TopicPrune(dspy.Signature):
    question: str = dspy.InputField()
    allowed_labels: list[str] = dspy.InputField()
    seed_nodes: str = dspy.InputField(desc="UUID to canonical-name mapping")
    width: int = dspy.InputField()
    selected_ids: list[str] = dspy.OutputField(desc="Subset of supplied UUIDs")

class CombinedRelationPrune(dspy.Signature):
    question: str = dspy.InputField()
    allowed_labels: list[str] = dspy.InputField()
    relation_options: str = dspy.InputField(desc="JSON relation options")
    width: int = dspy.InputField(desc="Maximum relations per topic")
    selected_option_ids: list[str] = dspy.OutputField(desc="Copied option IDs")
    scores: list[float] = dspy.OutputField(desc="Relevance scores from 0 to 1")
    explanation: str = dspy.OutputField(desc="Why selected relations help")
\end{verbatim}
\end{latin}

class Judge(dspy.Signature):
    generated_clinical_triple: str = dspy.InputField()
    retrieved_knowledge_graph_facts: str = dspy.InputField()
    support_score: str = dspy.OutputField(desc="Integer from 0 to 10")
    reasoning: str = dspy.OutputField(desc="Brief support reasoning")
extractor = dspy.Predict(ExtractClaims)
judge = dspy.Predict(Judge)
